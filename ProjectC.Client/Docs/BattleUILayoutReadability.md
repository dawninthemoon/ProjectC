# 전투 카드 배치와 가독성 개선

기준 화면은 1920×1080. `BattleScreen`, `BattleCard`, `BattleFieldCard`, `CardBack` 프리팹 및 `BattleVisualSettings`를 수정했다. 손패와 필드는 별도 프리팹과 기존 `CardWidget`/서버 데이터를 그대로 사용한다. 필드 프레임은 기존 180×228 비율을 유지해 이미지를 찌그러뜨리지 않았고, 두 필드 행의 중심을 약 y363과 y616으로 배치했다. 서버가 제공하는 FieldLimit을 계속 사용하며 5장을 초과하면 기존 방식으로 축소한다.

기본과 확장 손패의 배율은 1.055로 조정해 180×244 프리팹의 몸체가 약 190×257이 된다. 5장 중심 간격은 최대 200이고 장수가 늘면 영역 안에서 겹친다. 양쪽 카드가 기울어지는 부채꼴이며 Hover한 카드를 앞으로 이동·확대한다. 기본 손패에서 Hover하면 기존 카드 상세 패널에 전체 이름, 능력치와 효과가 표시되고 커서가 떠나면 닫힌다. 선택된 상세는 유지한다. 오른쪽에서 이동하는 드로우와 카드 슬롯 계산은 기존 경로를 사용한다.

상대 손패는 82×130 뒷면과 약 74px 간격으로 표시한다. 프로젝트에 여우 뒷면 Sprite가 없어 레퍼런스를 바탕으로 `Assets/Art/UI/BattleCardBack/FoxCardBack.svg`와 PNG를 새로 그렸다. 기존 `CardBack` 프리팹에 연결했고 숨겨진 위젯의 카드 데이터와 일러스트는 표시하지 않는다. 이 벡터 그림은 레퍼런스의 정교한 원화보다 단순하다.

이름 띠, HP·공격·체력·비용 및 턴/페이즈 문구의 크기·색상·TMP 외곽선 재질을 조정했다. 이름은 유지하며 긴 이름은 띠에서 줄임표로 표시하고 상세 패널에 전체 이름이 나온다. 선택·서버가 제공한 사용 가능 상태를 나타내는 기존 발광은 재사용한다. 카드 뒷면이 커지면서 겹치던 턴 텍스트는 화면 왼쪽 위로 옮겼다.

## 캡처 및 검증

- `Artifacts/BattleLayoutReadability/reference-vs-unity.png`는 원본 레퍼런스와 3장 필드·5장 손패 합성 스냅샷을 나란히 놓은 비교다. `hand-1`, `hand-5`, `hand-10`, `hand-10-hover`, `field-1`, `field-3`, `field-5`, `field-10` PNG는 동일한 실제 Unity BattleScene에서 여러 카드 정의와 서로 다른 숫자를 사용해 캡처했다. 실제 온라인 경기 캡처는 아니다.
- `results.xml`: 1920×1080 렌더, 카드 화면 경계, Hover/상세 패널, 상대 비공개 뒷면과 손패·필드·턴 버튼 Raycast 1/1 통과.
- `input-regression.xml`: 기존 드로우 표현, GameplayInput 및 실제 로컬 서버의 드로우·카드 드래그·공격·재대결 시나리오 총 20/20 통과. 서버를 지정한 선택형 효과의 거부·재선택 검사도 포함한다. 서버는 기존 `/tmp/projectc-hand-server-build/ProjectCNetworkServer` 바이너리를 사용했다.
- 별도 `regression.xml`은 서버 경로 없이 실행한 첫 결과로 19/23 통과했다. 서버 경로 미설정 1건은 서버 지정 후 통과했다. 손패 테스트 2건은 이전 0.513 배율/무회전을 고정 요구해 현 디자인과 맞지 않는다. 바깥 클릭 테스트 1건은 `BattleRenewalStage2.md`에 이전부터 기록된 실패이며 이번에 해결했다고 주장하지 않는다. 기존 테스트 기대값은 변경하지 않았다.

## 남은 차이와 한계

레퍼런스의 정교한 금속 가공, 곡선 영웅 장식, 턴 버튼, 유틸리티와 자원 트레이는 기존 아트와 배치가 남아 있다. 손패 10장은 프레임이 서로 겹치므로 전체 정보 확인에는 Hover가 필요하다. 필드 10장은 영역에 맞춰 축소되므로 이름과 작은 수치는 5장보다 읽기 어렵다. 더 큰 FieldLimit에 대한 가독성 개선과 1920×1080 이외 해상도, 실제 사용자 장시간 플레이는 이번에 검증하지 않았다. PNG의 이미지와 카드 수치는 테스트용이며, 여우 뒷면과 텍스트 재질 외의 새 아트는 제작하지 않았다.
