# 전투 UI 리뉴얼 2단계

## 적용 범위

- `Assets/Prefabs/Battle/BattleScreen.prefab`: 전장 가이드, 양 필드 및 드롭 영역, 손패, 상대 초상화, 양쪽 존 표시와 드로우 출발점 배치. 기존 `BattleScene.unity`는 이 프리팹을 사용하며 씬 파일은 변경하지 않았다.
- `BattleCard.prefab`, `BattleFieldCard.prefab`: 회색 사각형 바탕을 프레임 실루엣과 절단형 안쪽 바탕으로 변경했다. 선택 테두리와 카드의 기존 Image/Raycast 및 데이터 연결은 유지한다.
- `BattleVisualSettings.asset`: 확장 손패 크기를 0.9로 조절했다. `CardTableLayout.cs`는 손패 장수에 따른 간격과 최대 7도 부채꼴을 계산하며, 선택된 카드는 정면으로 확대한다. `BattlePresenter.cs`의 기존 화면 경계 계산에 회전된 카드의 높이를 반영하고, 손패 폭과 위치를 조절했다. 기존 드로우는 동일한 GetSlot과 기존 오른쪽 덱 출발점을 사용한다.
- `Assets/Art/UI/BattleRenewalStage2/`: 편집 가능한 `ArenaGuides.svg`, `CardInset.svg`, `ZoneVertical.svg`와 PNG. 각각 공통 전장 가이드, 카드 바탕, 존 프레임이다. 전장 가이드는 Raycast를 받지 않는다.
- `Assets/Editor/ApplyBattleRenewalStage2.cs`: 명시적으로 실행하는 에디터 적용 도구. 실행할 때 프리팹 배치와 확장 손패 설정을 이 단계 값으로 다시 저장한다.
- `Assets/Tests/PlayMode/BattleRenewalStage2PlayModeTests.cs`: 실제 BattleScene과 합성 서버 스냅샷으로 화면 배치 및 Raycast를 검사한다.

## 배치와 데이터 경계

기존 씬의 교체 가능한 3D 신사 전장 위에 비테마 공통 청록/금색 가이드를 얹는다. 가이드의 반투명 바탕은 카드 뒤의 명도 대비를 높인다. 3D 모델과 UI 가이드는 각각 별도 오브젝트다. 상대 손패/영웅은 위, 내 영웅과 손패는 아래, 존은 오른쪽 위·아래, 턴 조작은 오른쪽 중앙에 둔다. 기존 요력 패널은 유지한다. 스냅샷에 전투 RP 필드가 없으므로 임의 값을 표시하지 않았다.

기본 데이터의 필드 한도는 5장이고 서버 설정은 최대 32장까지 허용한다. 필드 중심 간격은 콘텐츠 영역 폭에 맞춰 제한하므로 영역 바깥으로 밀어내지 않지만, 5장보다 많은 설정에서는 카드가 겹치며 32장 가독성은 별도 개선이 필요하다. 손패는 0/3/5/8/10장에 대해 검사했다. 내 덱은 기존 비공개 덱 조회 경로를 사용하고, 양쪽 묘지/제외는 기존 공개 갤러리를 사용한다. 상대 덱은 수량만 표시하며 목록 조회 동작은 만들지 않았다.

## 실제 장면 캡처와 확인

`Artifacts/BattleRenewalStage2/`에 1920×1080, 2560×1440, 1920×1200(16:10), 2520×1080(21:9)의 5장 및 10장 PNG가 있다. Unity 6000.0.81f1의 PlayMode에서 실제 BattleScene과 합성 공개 스냅샷을 사용해 캡처했다. 온라인 경기 캡처는 아니다. `BattleRenewalStage2-layout.xml`은 네 화면별 0/3/5/8/10장과 마지막 카드 확대에서 카드의 화면 경계, 내 필드/영웅/턴 버튼/존 겹침, 상대 HP와 필드 겹침을 검사한 결과 1/1 통과다. `BattleRenewalStage2-layout-batch.xml`은 같은 기하 검사에 내 덱과 양쪽 묘지/제외 버튼의 실제 UI Raycast 검사를 추가한 결과 1/1 통과다. 배치 모드에서는 스크린샷을 만들지 않는다.

`BattleRenewalStage2-regression.xml`: 지정한 기존 PlayMode 회귀 25개 중 21 통과, 4 실패. 드로우 표시 12개 및 GameplayInput 범위 테스트 7개, 장면 Raycast 테스트는 통과했다. 실제 서버를 지정한 온라인 테스트는 본문 검증 후 종료 정리에서 파괴된 `CardGalleryView` 접근 예외로 실패했다. 손패 바깥 클릭 테스트는 1단계 변경 전/후 비교에서도 같은 실패였다. 나머지 두 손패 테스트는 확장 크기 1.161 및 회전 0도를 요구하는 기존 기대값이 0.9 및 부채꼴과 달라 실패했다. 기존 테스트 기대값은 수정하지 않았다. 전체 테스트나 사람의 두 창 실플레이 통과를 의미하지 않는다.

## 레퍼런스와 남은 차이

공통 가이드와 양 진영 위치 관계를 개선했으나 레퍼런스의 원근감 있는 달빛 배경, 정교한 금속/곡선 장식, 카드와 영웅 HUD 아트, 상대 손패 뒷면 및 수직 자원 트레이는 아직 재현하지 못했다. 현재 배경은 기존 테마 모델이며 새로운 레퍼런스급 테마 배경을 제작한 것은 아니다. RP를 실제로 표시하려면 서버가 제공하는 권위 있는 전투 데이터와 별도 설계가 필요하다. 상대 덱은 정보 보호를 위해 비공개 목록 버튼을 제공하지 않는다. 32장 필드의 가독성, 실제 입력 장치로 하는 장시간 플레이 및 완전한 온라인 회귀는 미검증이다.
