# 전투 UI 리뉴얼 1단계 작업 기록

현재 결과는 부분 적용이며 레퍼런스의 완성도와 전체 회귀 조건에 도달하지 않았다.

- 원본과 PNG: `Assets/Art/UI/BattleRenewal/`의 FieldFrame, TurnFrame, HeroFrame, HpBadge, RpBadge, ZoneFrame. SVG는 편집 가능한 원본이다. 텍스트와 수치는 포함하지 않는다. RP 배지는 제작만 했으며 실제 RP 데이터와 연결하지 않았다.
- `BattleCard.prefab`에 입력을 받지 않는 프레임 오버레이를 추가했다. `BattleFieldCard.prefab`은 필드 전용 복사본이며 180×228이다. 손패는 기존 180×244 카드와 기존 비행 경로를 유지한다.
- `BattleScreen.prefab`의 필드 프리팹 참조, 턴 버튼, 영웅 프레임/HP, 존 장식 및 일부 위치를 변경했다. `BattleScene`은 변경하지 않았다. 존 장식은 클릭을 받지 않는다. 기존 필드 입력과 턴 명령 코드를 변경하지 않았다.
- 이미지 추정: 원본 1671×941에서 필드 카드 외곽 약 150×190 (0.79), 턴 버튼 약 210×310 (0.68). Unity 필드 카드 180×228 (0.789), 턴 버튼 210×310 (0.677). 손패는 기울기와 겹침으로 정확한 외곽 측정이 어렵고 기존 180×244 (0.738)를 유지했다. 레퍼런스 이미지 기반 추정이며 정밀 계측이 아니다.
- 비교용 합성 1920×1080 Unity 프리뷰: `Artifacts/BattleRenewal/Before-Compact.png`, `After-Compact.png`, `Before-Expanded.png`, `After-Expanded.png`. 기존 프리뷰는 실제 경기나 런타임 손패 경계 보정을 실행하지 않으며 확장 손패가 화면 아래에서 잘린다. 전후 비교는 현재 프리팹의 수동/온라인 검증을 대체하지 않는다.
- 2560×1440, 16:10, 21:9와 손패 10장 실제 실행 캡처는 수행하지 않았다. 레퍼런스의 금속 질감과 곡선, 카드별 배지, 부채꼴 손패, 배경/전장 가이드, 배치와 장식은 아직 크게 다르다. 9-slice는 사용하지 않았다.
- 다음 셰이더 작업에는 각 프레임의 금속 전용 마스크, 거리/진행 좌표, 발광 마스크와 고정 광택 분리본이 필요하다. 제공 SVG 윤곽은 출발점이지만 이 마스크들은 아직 제작하지 않았다.
- Unity 6000.0.81f1 PlayMode 전체: 115개 중 83 통과, 32 실패. 서버 실행 파일/테스트 데이터 누락 및 기타 UI·데이터 실패 포함. 개별 결과 `Artifacts/BattleRenewal/playmode.xml`.
- 관련 19개 테스트: 16 통과, 3 실패. 기존 사용자 코드 변경을 유지하고 변경 전 두 프리팹으로 실행한 비교에서도 동일한 3개가 실패했다. 결과는 `focused.xml`, `focused-before.xml`. 이는 전체 기능 회귀 통과를 뜻하지 않는다. 실제 두 클라이언트 재접속, 선택 효과, 턴 종료와 드로우는 별도 미검증이다.
