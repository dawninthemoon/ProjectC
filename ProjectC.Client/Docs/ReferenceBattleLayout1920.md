## 예외와 남은 차이

- `enemy_rp_badge`, `hero_rp_badge`, `topleft_extra_panel`, `yokai_tray_row_2`~`row_5`: 대응하는 전투 데이터가 없어 표시하지 않는다. 요력 트레이는 실제 값 1행만 사용하므로 전체 패널은 목표 (352,782,148,266) 대신 (352,797,148,68)이다. 최대 요력이 0이면 양쪽 요력 패널을 숨긴다.
- `side_button_log`: 기존 History 버튼은 (24,150,230,54), 목표는 (37,380,70,115)다. 목표 위치는 열려 있는 카드 상세창과 겹쳐 기존 기록 버튼 위치를 유지했다. `side_button_chat`과 `settings_button`은 대응하는 독립 기능이 없어 추가하지 않았다.
- `keyword_slot` RectTransform은 목표 크기·위치로 준비했지만 실제 키워드 상태 바인딩이 없어 표시하지 않는다. 기존 의미 없는 두 점을 다시 표시하지 않았다.
- `enemy_portrait`의 285×215 영역 안 실제 일러스트와 원형 프레임은 215×215다. 가로로 늘리지 않기 위한 선택이며 레퍼런스의 넓은 아치와 장식은 새 아트가 필요하다. 아군 원형도 325×325로 표시된다.
- 카드 원화의 구도는 레퍼런스와 다르므로 필드 크롭만으로 얼굴 방향을 바꿀 수 없다. 턴 버튼의 외곽과 금속선은 새 벡터지만 레퍼런스의 꽃·회화 질감까지 동일하지 않다. 스프라이트 경계에는 투명 여백이 있으므로 눈에 보이는 선의 위치는 RectTransform 경계와 다를 수 있다.
- 필드 카드 10장은 화면 안에 들어가지만 기존 폭 맞춤 방식에 따라 프레임이 약 80×88px까지 작아져 능력치 가독성이 떨어진다. 확대나 스크롤 등 별도의 밀집 필드 표현은 아직 구현하지 않았다.
- 본 검증은 1920×1080 Game View 기준이다. 다른 종횡비의 최종 레이아웃을 합격했다고 가정하지 않는다.

- 카드 현지화 테스트 25건 중 24건 통과. 나머지 `NewFactionsUsePublishedStatsTextCostsAndExistingArtworkFallback`은 기존 카드 설명 서식의 원문 `{0}`과 이미 치환된 `1`의 비교에서 실패한다. 이번 수정은 해당 카드 설명 데이터를 변경하지 않았다.
