# 백귀야행 Sunset Cel UI — 분리 리소스 v1

ProjectC의 기존 UI SVG 명목 치수에 맞춰 새로 그린 **14종의 독립 리소스**입니다. 원본 GitHub 프로젝트에는 파일을 덮어쓰거나 프리팹을 수정하지 않았습니다.

## 구성

| PNG / SVG 파일명 | 원본 기준 크기(px) | 용도 |
|---|---:|---|
| HandCardFrame | 180 × 244 | 손패 카드 외곽 프레임(내부 투명) |
| FieldMonsterFrame | 180 × 228 | 세워진 필드 몬스터용 둥근 모서리 프레임(내부 투명) |
| HandTitlePlate | 150 × 32 | 가운데 정렬 카드명용 빈 명패 |
| HealthBadge | 48 × 52 | **왼쪽** 체력/수비력 뱃지, 숫자 없음 |
| AttackBadge | 48 × 52 | **오른쪽** 공격력 뱃지, 숫자 없음 |
| FloralCardBack | 360 × 540 | 덱과 상대 손패에 공통 사용되는 꽃무늬 뒷면 |
| TurnStatusBase | 640 × 236 | 턴 번호/내 턴·상대 턴용 빈 상태판 |
| TimerRingFrame | 224 × 224 | 남은 시간용 **빈 링 장식** |
| ZoneOmamoriBase | 166 × 230 | 덱·묘지·제외 공통 부적형 빈 상태판 |
| PhaseButtonBase | 468 × 720 | 메인/배틀/턴 종료용 빈 버튼 베이스 |
| PhaseArrow | 88 × 48 | 별도 화살표 아이콘 |
| ZoneIconDeck / Grave / Exile | 각 64 × 64 | 덱/묘지/제외 아이콘 |

`png/`에는 바로 임포트 가능한 투명 배경 PNG가, `svg/`에는 재편집 가능한 원본 벡터가 있습니다. `manifest.json`은 파일별 크기와 동적 요소 사용 정보를 담고 있습니다.

## Unity 적용 시 주의사항

1. 모든 PNG를 `Texture Type = Sprite (2D and UI)`로 임포트합니다. 프로젝트의 기존 Canvas/RectTransform 배치와 이벤트 연결은 유지합니다.
2. 카드 일러스트는 **프레임 아래**에 놓습니다. `HandCardFrame`/`FieldMonsterFrame` 내부는 투명하며, 구 `CardInset`을 중첩하면 돌출/잘림이 다시 발생하므로 새 프레임과 아트의 실제 마스크 경계를 맞춰야 합니다.
3. `HandTitlePlate` 위에는 기존 TMP 카드명 텍스트를 **가운데 정렬**해 얹습니다. 별도의 마나 코스트 영역은 없습니다.
4. `HealthBadge`는 카드 좌측 하단, `AttackBadge`는 우측 하단에 배치합니다. 스탯 숫자는 별도의 TMP 컴포넌트로 표시합니다. (현재 프리팹의 공격/체력 연결 순서와 다르다면 **연결을 확인**하세요.)
5. `FloralCardBack`을 덱 뒷면과 상대 비공개 손패의 동일한 스프라이트로 지정합니다. 비공개 카드 앞면을 렌더링하지 않도록 기존 권한 제어를 유지합니다.
6. 턴/페이즈 이름, 턴 번호, 타이머 초, 덱/묘지/제외 장수 등은 **이미지에 인쇄되지 않았습니다**. 기존 바인딩된 TMP 컴포넌트를 위에 유지합니다.
7. `TimerRingFrame`은 정적 테두리입니다. 시계 방향/반시계 방향으로 줄어드는 게이지는 프로젝트 기존 `Image.Type = Filled`, `Fill Method = Radial 360` 또는 별도의 셰이더로 이 링 **안쪽/아래 별도 레이어**에서 처리하세요. 이 PNG 자체를 Filled 이미지로 사용하지 마세요.
8. `PhaseButtonBase`의 중앙은 비워 두었습니다. `PhaseArrow`와 TMP 페이즈명을 별도 오브젝트로 구성합니다.
9. 캔버스 스케일러/앵커/레이아웃은 기존 프로젝트를 기준으로 합니다. 이 팩의 픽셀 치수는 대응 원본 스프라이트의 명목 아트보드 치수이지, 최종 화면에서 강제해야 할 RectTransform 크기를 의미하지 않습니다.

## 스타일

일본 판타지의 꽃·물결 장식, 평평한 면 분할과 선명한 윤곽의 셀채색 문법을 사용했습니다. 배경은 먹색·버건디, 포인트는 차분한 산호빛 노을색·아이보리, 공격 스탯만 청회색으로 구분했습니다. 기존 작품의 카드 뒷면 문양은 재사용하지 않았습니다.

## 재생성

`python build_assets.py`로 동일한 SVG 및 PNG를 재생성할 수 있습니다. PNG 래스터화에는 Inkscape CLI가 필요합니다.
