# ProjectC UI — 목업 기반 셀채색 리페인트 v4

첨부된 전투 목업을 기준으로 다시 그린 **Unity용 게임 UI 리소스 21개**입니다.

- `Unity/Assets/Art/UI/Battle/MockupRepaint/` — Unity에 복사할 PNG 21개. 배경 1920×1080, 나머지는 투명 스프라이트.
- `SourceHighRes/` — 축소 전 고해상도 개별 원본.
- `SourceSVG/` — 작은 버튼 화살표 2개에 사용한 수정 가능한 벡터 소스.
- `Preview/` — 목업 참고 이미지, 부품 시트, 타이머 조립 예시. **이 폴더의 정적 코스트 예시는 게임 UI에 쓰지 말 것.**
- `Docs/Unity_Setup.md` — GitHub ProjectC 프리팹/스크립트 기준 연결 대상, 가변 TMP, 타이머 `fillAmount`, 특수 코스트 스크롤/확장 설명.

스타일은 2D 셀채색의 붉은 장식·벚꽃·얇은 금색 선·먹색 배경을 사용하며, 강한 3D 광택이나 과도한 반사를 넣지 않았습니다. 배지는 비어 있고, 카드 일러스트·영웅 초상화·텍스트는 게임이 실시간으로 넣습니다.

**중요:** 원본 레이어 파일을 추출한 것이 아니라 목업을 참조해 새로 그린 디자인입니다. 픽셀 단위로 완전히 동일한 결과를 보장할 수는 없으며, 최종 Unity 배치/애니메이션 및 프리팹 교체 작업은 아직 수행되지 않았습니다. 자세한 적용 방법은 `Docs/Unity_Setup.md`에 있습니다.
