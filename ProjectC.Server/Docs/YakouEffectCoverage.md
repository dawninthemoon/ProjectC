덱 위 선택에서 선택하지 않은 카드들은 원래 순서대로 덱 아래에 놓는다. 덱에 지정된 수량보다 적게 남은 경우는 규칙을 임의로 정하지 않고 거부한다.

온라인 프로토타입은 지원된 소환·주문 트리거를 자동 처리하고 선택·우선권·스냅샷·재접속을 제공한다. 습격 응전 3016/2011/3018/3019와 주문 무효 3020은 명시적으로 지원한다. 이외의 유료 주문 비용, 여러 미구현 효과, 일반적인 응전 체인과 전체 카드 커버리지는 미완성이다. 3012의 유료 발동은 현재 응전 창 없이 해결 경로에 들어간다. `RuntimeReady`는 false다.

카드 2002의 한국어 설명은 선택 회수를 언급하지만 실제 JSON에는 `Optional` 속성이 없다. 데이터를 임의로 변경하지 않고 현재 JSON을 따른다.
