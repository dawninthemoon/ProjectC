# 야행 카드 효과 지원 현황

덱 위 선택에서 선택하지 않은 카드들은 원래 순서대로 덱 아래에 놓는다. 덱에 지정된 수량보다 적게 남은 경우는 규칙을 임의로 정하지 않고 거부한다.

온라인 프로토타입은 지원된 소환·주문 트리거를 자동 처리하고 선택·우선권·스냅샷·재접속을 제공한다. 습격 응전 3016/2011/3018/3019와 주문 무효 3020은 명시적으로 지원한다. 유료 메인 주문도 응전 창을 열지만, 여러 미구현 효과와 일반적인 응전 체인 및 전체 카드 커버리지는 미완성이다. `RuntimeReady`는 false다.

카드 2002의 한국어 설명은 선택 회수를 언급하지만 실제 JSON에는 `Optional` 속성이 없다. 데이터를 임의로 변경하지 않고 현재 JSON을 따른다.

## Alpha 01 온라인 연결 갱신

- 신규 4001–4021의 작성된 소환·비용·선택·전투·응전 형태를 서버가 검증하고 처리한다. 4002는 비용 지불 후 조건을 검사하며 비용 카드는 회수 후보에서 제외한다. 4006 역시 제외한 비용을 회수하지 않는다. 4012는 서로 다른 1–2개 대상을 선택하고 4017은 방어자 교체와 첫 피해 감소를 한 응전에서 처리한다. 4018은 배정된 방어자가 없으면 발동할 수 없고 4020은 묘지 카드 두 장을 제외 비용으로 지불한다.
- 기존 2010은 묘지의 적법한 몬스터와 빈 필드 칸을 서버가 제시하며 선택한 칸에 특수 소환한다. 기존 3013은 강령 비용의 회수 주문 선택지에 포함된다. 두 주문 모두 응전 창 이후 선택을 제공한다.
- 신규 효과의 정상·거부 경로는 `YakouMatchTests`와 `YakouCommandGatewayTests`에서 검증한다. 여섯 Alpha 덱 조합은 실제 WebSocket 두 연결에서 몬스터 소환, 습격 또는 덱 소진을 거쳐 승패까지 진행한다. 이 시나리오는 전체 카드 사용률이나 덱 밸런스를 측정하지 않는다.
- 아직 온라인 미지원인 기존 효과에는 2101의 관통 부여, 3009의 적 주문 지정 반응, 3017의 효과 피해 방지가 있다. `RuntimeReady`는 여전히 false다.

## 유료 주문 응전 창 보강

- `BeginSpellResponse`는 작성된 폐기·강령 비용을 검증하고 지불한 뒤 상대에게 응전 우선권을 준다. 기존 네트워크 명령 `ActivateMainSpell`도 동일한 창으로 진입하므로 직접 해결로 우회할 수 없다. 습격·주문 응전 전용 카드는 메인 단계 주문 경로에서 거부한다.
- 두 플레이어가 패스하면 원래 주문이 해결된다. 선택이 필요한 효과는 그때 소유자에게만 `PendingSelection`을 보여준다. 상대 응전으로 무효화되면 비용과 사용한 주문은 이동한 영역에 남고 대상 선택은 생성되지 않는다. 잘못된 비용·권한·대상은 복사본 상태에서 거부한다.
- 주문 응전 체인은 최대 8개 링크에서 3020/4020의 무효화 주문을 번갈아 중첩하며 후입선출로 해결한다. 각 응전은 현재 우선권 보유자가 맨 위 상대 주문에만 사용할 수 있다. 습격 응전과 다른 주문 효과의 일반적인 혼합 중첩 및 위 세 가지 기존 미지원 효과는 여전히 구현되지 않았다. `RuntimeReady`는 false다.

## 2012 다음 피해 이벤트 보호

- 대상은 주문 응전 창이 닫힌 뒤 소유자만 선택한다. 검증된 필드 인스턴스에 보호량 2를 기록하고 공개 필드 스냅샷에도 표시한다. 여러 보호가 같은 인스턴스에 있으면 기존 피해 감소 합산 방식처럼 합산하며, 다음 양의 전투 피해 한 번에 적용 후 모두 소비한다. 피해가 0이면 유지한다. 턴이 바뀌어도 다음 피해 이벤트까지 지속하고 필드 이탈 시 제거한다.
- 현재 55종 카드 정의에는 직접적인 효과 피해 연산이 없다. 효과 피해 경로가 추가되면 이 보호를 해당 피해 이벤트에도 적용해야 한다. 지금 검증한 피해 이벤트는 전투 피해이다.

## 3015 현현 조건 면제

- 작성된 폐기 비용 2를 지불하고 주문 응전 창이 닫히면 이번 턴 면제 횟수 1을 부여한다. 현현 시 인쇄된 조건 각각의 실패를 계산한다. 실패가 0이면 면제를 보존하고, 실패가 1이면 면제를 소비하며, 실패가 2 이상이면 거부한다. 기력 비용과 턴당 현현 횟수는 면제 대상이 아니다. 턴 종료 시 남은 면제는 사라진다.
- 현재 작성된 현현 카드 2101/2102에서는 3015의 폐기 비용 두 장이 묘지 조건 자체를 채울 수 있다. 실제 카드 데이터에서 조건 면제가 필요한 상황이 빈번한지는 별도 플레이테스트가 필요하다. 다중 실패·충족 조건 사례는 조건 수치만 바꾼 테스트 카탈로그로 검증했다. 실제 카드 JSON은 바꾸지 않았다.
